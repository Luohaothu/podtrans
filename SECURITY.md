# Security Policy

## Reporting a vulnerability

Please report security issues through [GitHub private vulnerability reporting](https://github.com/Luohaothu/podtrans/security/advisories/new) for this repository.

Do not open a public issue for a security report. If that form is not available yet, please wait until private vulnerability reporting is enabled on the repository rather than posting details in public.

This project does not offer a bug bounty.
